TAIT ROSTER UPDATER

The finished app is built from Python on a Windows computer.

EASIEST WAY TO TRY IT
1. Double-click run_app.bat.
2. Choose one company-approved shared folder.
3. Click Initialize baseline and choose the approved roster workbook.
4. Choose Sven's monthly file and click Run update.

FOR A SINGLE WINDOWS APP FILE
1. Double-click build_windows_app.bat on a Windows computer.
2. When it finishes, open the dist folder.
3. Give coworkers TAIT Roster Updater.exe.
4. Each coworker chooses the same shared roster folder on first use.

The first setup downloads the required Python packages. If company security
blocks the setup or the unsigned .exe, ask IT to review and package/sign it.

The sample_data folder contains fake employees only. It can be used to test
the workflow without using Sven's real monthly pull.
